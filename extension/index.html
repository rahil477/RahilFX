Quick start

Select clips or layers in the host timeline, then use Edit. Subtitle tools work with text you provide.

Save a project copy before applying changes. Use the host application's Undo if needed.

Speed control

Apply a constant speed change to selected clips (Premiere) or selected layer stretch (After Effects).

After Effects tools

These operations apply only to an active After Effects composition and are grouped in Undo.

Feature status

Host-specific tools are under active development; feel free to test speed and layer helpers on a duplicate project before shipping work.

Manual subtitle helper

Paste a transcript. It will be split into short caption cues and exported as an SRT file. No automatic transcription or translation is performed.

Review timing and text before importing the SRT into your editing project.
